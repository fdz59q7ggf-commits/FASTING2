# 斷食計時器

長時間斷食計時器，支援離線使用（PWA），並提供：

- 圓環進度顯示已過時間百分比與里程碑徽章（12/24/36/48/72/96/120/144/168 小時）
- 依據斷食時數自動顯示目前所處階段與身體變化說明
- 記錄體重、心跳、血糖、血壓，並保留歷史清單
- 每項數據皆有獨立趨勢折線圖（最近 20 筆），血壓圖同時顯示收縮壓與舒張壓
- 資料存在瀏覽器本機（localStorage），離線或重新整理也不會遺失
- 達成每個里程碑與目標時數時可跳出瀏覽器通知（需允許通知權限，頁面需開啟）
- 斷食歷史紀錄（可編輯筆記、刪除）與統計
- 匯出 / 匯入 JSON 備份（可選擇取代或合併）、匯出 CSV
- 血糖、心跳、血壓異常時顯示警示
- 隱私同意機制：未同意時資料不會儲存；可一鍵刪除本機資料
- 斷食進行中自動要求螢幕常亮（瀏覽器支援時）
- 快捷鍵：1 / 2 / 3 切換頁籤
- 自訂目標時數（1–720 小時）、血糖 mg/dL ↔ mmol/L、體重 kg ↔ lb
- 喝水 / 電解質定時提醒（頁面開啟時）、長時間斷食後的復食提醒
- 趨勢圖可切換 7 天 / 30 天 / 全部，並顯示日期與高低值
- 可安裝成 App（支援的瀏覽器）、預設跟隨系統深淺色
- 深色「生理監測儀」風格介面，心電圖脈動線作為視覺主軸

## 部署方式（GitHub Pages，免費）

1. 到 https://github.com 建立一個新的 public repository
2. 把這個資料夾內的檔案（index.html、manifest.json、icon.svg、sw.js、icon-*.png）上傳上去
3. 進入 repo 的 **Settings → Pages**
4. Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，儲存
5. 等 1-2 分鐘，會拿到網址 `https://你的帳號.github.io/repo名稱/`

## 使用方式

1. 設定「斷食開始時間」與「目標時數」，按「開始斷食」
2. 圓環會顯示已過時間百分比，並依時數點亮里程碑徽章
3. 下方卡片會顯示目前階段名稱與身體變化說明
4. 可隨時在「記錄體重 / 血糖 / 血壓」區塊新增數值，會存成一筆歷史紀錄
5. 按「結束斷食」即可停止計時

## 重要提醒

各階段之身體變化說明僅供一般參考，個體差異大，並非醫療建議。超過 24–48 小時的長時間斷食建議在醫師或營養師監督下進行；若有糖尿病、低血糖、心血管疾病、服用藥物、懷孕或曾有飲食失調經驗，請先諮詢專業醫療人員。若斷食期間感到頭暈、心悸、極度不適，請立即停止並補充飲食。
