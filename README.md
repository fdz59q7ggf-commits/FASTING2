# 斷食計時器

長時間斷食計時器，支援離線使用（PWA），並提供：

- 圓環進度顯示已過時間百分比與里程碑徽章（12/24/36/48/72/96/120/144/168 小時，之後每 24 小時一個，最多到 336 小時），圓環顏色依代謝階段變化
- 依據斷食時數自動顯示目前所處階段與身體變化說明
- 記錄體重、心跳、血糖、血壓，並保留歷史清單；可指定記錄時間補登過去的數據
- 每項數據皆有獨立趨勢折線圖（最多顯示最近 60 筆），血壓圖同時顯示收縮壓與舒張壓
- 資料存在瀏覽器本機（localStorage），離線或重新整理也不會遺失；同時開好幾個分頁時會自動同步，不會互相覆蓋
- 達成每個里程碑與目標時數時可跳出通知（透過 Service Worker 顯示，Android 也能正常收到；點通知會切回 App）。「記錄」頁顯示通知是否開啟，可一鍵開啟或傳送測試通知
- 離開後回來（切到背景或重新開啟 App 超過 10 分鐘），首頁會整理離開期間達成的目標、里程碑、目前階段與錯過的喝水提醒，並只慶祝一次
- 斷食歷史紀錄（可編輯開始 / 結束時間、目標時數與筆記）與統計
- 刪除單筆記錄、清空資料、匯入資料後都可在提示列按「復原」
- 匯出 / 匯入 JSON 備份（匯入前顯示筆數，可選擇合併、取代全部或取消）、匯出 CSV（本地時間、使用目前選擇的單位，可直接用 Excel 開啟）
- 血糖、心跳、血壓異常時顯示警示（依目前選擇的血糖單位顯示門檻）
- 隱私同意機制：未同意時資料不會儲存；拒絕同意時可選擇一併刪除先前已儲存的資料；可一鍵刪除所有本機資料（含設定與舊版資料）
- 斷食進行中自動要求螢幕常亮（瀏覽器支援時）
- 快捷鍵：1 / 2 / 3 切換頁籤
- 目標時數可選 16–336 小時或自訂（1–720 小時）、血糖 mg/dL ↔ mmol/L、體重 kg ↔ lb
- 喝水 / 電解質定時提醒、長時間斷食後的復食提醒
- 趨勢圖有座標軸，點選資料點可查看當次數值與時間；7 天 / 30 天 / 全部 的切換同時套用到數據統計卡與趨勢圖
- 症狀記錄（頭暈、心悸、噁心等，可複選）與次數統計
- 可安裝成 App（支援的瀏覽器）
- 淺色 / 深色主題：預設即時跟隨系統設定，手動切換後會記住你的選擇

## 部署方式（GitHub Pages，免費）

1. 到 https://github.com 建立一個新的 public repository
2. 把這個資料夾內的檔案（index.html、manifest.json、icon.svg、sw.js、icon-180.png、icon-192.png、icon-512.png）上傳上去
3. 進入 repo 的 **Settings → Pages**
4. Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，儲存
5. 等 1-2 分鐘，會拿到網址 `https://你的帳號.github.io/repo名稱/`

## 使用方式

1. 設定「開始時間」與「目標時數」（或點 16h / 18h / 20h / 24h / 自訂），按「開始斷食」；沒改開始時間時會以按下的當下為準
2. 圓環會顯示已過時間百分比，並依時數點亮里程碑徽章
3. 下方卡片會顯示目前階段名稱與身體變化說明
4. 可隨時到「記錄」頁新增體重、心跳、血糖、血壓與症狀，會存成一筆歷史紀錄
5. 斷食進行中，「結束斷食」是主要按鈕；按下後確認並可留下筆記，紀錄會出現在「統計」頁的斷食歷史。若要改用其他開始時間重新計時，先修改開始時間再按「重新開始」（已經過的里程碑不會再跳出慶祝）
6. 「統計」頁可查看斷食統計與歷史；下方「生理數據」區可切換 7 天 / 30 天 / 全部，統計卡與趨勢圖會一起變化

## 通知的限制

這是純網頁 App，沒有伺服器推播，提醒是由頁面本身計時觸發的：

- 手機切到背景或鎖定螢幕時，瀏覽器會暫停頁面，里程碑與喝水提醒可能要等回到 App 才會出現；回來時首頁會整理離開期間的進度
- 斷食中保持本頁開著、螢幕亮著（App 會自動要求螢幕常亮），提醒最準時
- iPhone / iPad 需先用 Safari「加入主畫面」，再從主畫面開啟才能使用通知（iOS 16.4 以上）
- 若通知被封鎖，需到瀏覽器的網站設定中重新允許

## 重要提醒

各階段之身體變化說明僅供一般參考，個體差異大，並非醫療建議。超過 24–48 小時的長時間斷食建議在醫師或營養師監督下進行；若有糖尿病、低血糖、心血管疾病、服用藥物、懷孕或曾有飲食失調經驗，請先諮詢專業醫療人員。若斷食期間感到頭暈、心悸、極度不適，請立即停止並補充飲食。
